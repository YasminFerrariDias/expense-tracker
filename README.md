# Expense Tracker

Aplicação web para controle de despesas, permitindo adicionar, visualizar e remover gastos, com atualização automática do total.

## Tecnologias

- [HTML5](https://developer.mozilla.org/pt-BR/docs/Web/HTML) — estruturação da página
- [CSS3](https://developer.mozilla.org/pt-BR/docs/Web/CSS) — estilização e layout
- [JavaScript](https://developer.mozilla.org/pt-BR/docs/Web/JavaScript) — manipulação do DOM e lógica da aplicação

## Funcionalidades

- Adicionar despesas com nome, categoria e valor
- Remover despesas da lista
- Atualização automática do total
- Contagem dinâmica de despesas
- Formatação de valores em Real (R$)
