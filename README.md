# Controle de Despesas

Aplicação web para controle de despesas, permitindo adicionar, visualizar e remover gastos, com atualização automática do total. Estrutura HTML e CSS fornecidas em curso; lógica em JavaScript implementada por mim.

## Tecnologias

- [HTML5](https://developer.mozilla.org/pt-BR/docs/Web/HTML) — estruturação da página
- [CSS3](https://developer.mozilla.org/pt-BR/docs/Web/CSS) — estilização da interface
- [JavaScript](https://developer.mozilla.org/pt-BR/docs/Web/JavaScript) — lógica da aplicação e manipulação do DOM

## Funcionalidades

- Adicionar despesas com nome, categoria e valor
- Remover despesas da lista
- Atualização automática do total e contagem dinâmica de despesas
- Formatação de valores em Real (R$) com `toLocaleString`
